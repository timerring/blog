链表的常见知识：构造、删除与反转

从单链表的构造与遍历入手，练习常数时间删除节点，以及迭代和递归反转链表。

构造与遍历链表 #

可以简单构造一个链表，顺序是 1 -> 2 -> 3 -> 4，如下所示：

package org.ac;
import java.util.Scanner;

class Node {
    public int val;
    public Node next;

    public Node(int val) {
        this.val = val;
    }
}

public class Main {
    public static void main(String[] args) {
        Node head = new Node(1);
        head.next = new Node(2);
        head.next.next = new Node(3);
        head.next.next.next = new Node(4);

        for(Node p = head; p != null; p = p.next)
            System.out.println(p.val);
    }
}

AC 28. 在 O (1)时间删除链表结点 #

给定单向链表的一个节点指针，定义一个函数在 O(1)时间删除该结点。

假设链表一定存在，并且该节点一定不是尾节点。

数据范围 #

链表长度 [1,500]。

样例 #

输入：链表 1->4->6->8
      删掉节点：第2个节点即6（头节点为第0个节点）

输出：新链表 1->4->8

/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode(int x) { val = x; }
 * }
 */
class Solution {
    public void deleteNode(ListNode node) {
        // 由于只知道当前点，不知道当前点的上一个节点，因此没办法直接删除该节点
        // 采用的方法是将下一个节点的值复制到当前节点，然后直接删除下一个节点即可
        // 首先找到当前节点的下一个节点，并且存储
        ListNode next = node.next;
        // 将下一个节点的值复制到当前节点
        node.val = next.val;
        // 将当前节点指向下下个节点即可
        node.next = next.next;
    }
}

AC35. 反转链表 #

定义一个函数，输入一个链表的头结点，反转该链表并输出反转后链表的头结点。

思考题：

  • 请同时实现迭代版本和递归版本。

数据范围 #

链表长度 [0,30]。

样例 #

输入:1->2->3->4->5->NULL

输出:5->4->3->2->1->NULL

迭代版本：

后一个节点不断指向前一个节点，然后顺序移动两个节点，完成对整个链表的反转即可。

/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode(int x) { val = x; }
 * }
 */
class Solution {
    public ListNode reverseList(ListNode head) {
        if (head == null) return null;
        // 存储一前一后两个节点
        ListNode a = head, b = head.next;
        // 后节点不为空
        while(b != null) {
	        // 存储后一个节点的下一个节点
            ListNode c = b.next;
            b.next = a;
            a = b;
            b = c;
        }
        // 最后将原头节点指向空即可
        head.next = null;
        return a;
    }
}

递归版本：

重复调用，一直递归到边界情况再进行判断。

/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode(int x) { val = x; }
 * }
 */
class Solution {
    public ListNode reverseList(ListNode head) {
        // 为空或者就一个节点，没有反转的必要（递归边界条件）
        if (head == null || head.next == null) return head;
        // 层层递归，递归到只有两个节点
        // 新的头节点存一下，这里应该是已经递归到了一个节点的边界情况（5 -> NULL），此时new_head就是最后一个节点5。
        ListNode new_head = reverseList(head.next);
        // 原头节点4的下一个节点5指向头节点4
        head.next.next = head;
        // 原头节点4指向空
        head.next = null;
        // 返回新头节点5
        return new_head;
        // original: 1->2->3->4->5->NULL
        // round1: 1->2->3->4<-5 (4 -> NULL)
        // round2: 1->2->3<-4<-5 (3 -> NULL)
        // ...
    }
}
