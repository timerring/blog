Seaborn’s kdeplot() function is one way to draw density plots in Python. At present, Matplotlib does not have a specific function for drawing density plots, and plotting is generally performed in combination with the result of the gaussian_kde() function in the Scipy library.

The neighbors.KernelDensity () module in Python’s scikit-learn library provides six kernel functions—Gaussian, Tophat, Epanechnikov, Exponential, Linear, and Cosine—for kernel density estimation calculations. Python’s KDEpy library provides as many as nine kernel functions, including Gaussian, Exponential, Box, Tri, Epa, Biweight, Triweight, Tricube, Cosine.

Drawing a density plot using the kdeplot () function in Seaborn is relatively simple. Combined with the rugplot () function, it can draw the data distribution along the X axis. The other two methods are somewhat more troublesome than the kdeplot () function, but the density plots drawn by these two methods are clearer.

Note that the kernel density estimation results here are all obtained through the Gaussian kernel function.

Multiple Data Groups, the Same Kernel Function #

For multiple groups of sample data with different numerical distributions, we often use the same kernel function to fit them and draw the results as density plots. This situation generally occurs during the data exploration stage, and the methods above are often used to view the distribution of data in each dimension or compare differences between different data.

Below is a kernel density plot drawn with Matplotlib using the same kernel function for multiple groups of sample data, showing the distributions of different data.

Gradient Color Fill #

For a better visual effect, color mapping needs to be applied to the original data values used to draw the density plot; that is, a continuous gradient color bar is used to represent specific plotting values, and the corresponding colors fill the area within the density plot curve. Here, this effect needs to be implemented through a custom plotting method.

The figure below shows density plots filled with gradient color drawn using the Matplotlib, ProPlot, and SciencePlots libraries, respectively.

“Ridgeline” Plot #

When drawing density plots for multiple groups of data, in addition to using subplots to draw each group of data as described above, we can also stack the plotting results of multiple data groups, that is, represent them using a “ridgeline” plot (ridgeline chart).

A “ridgeline” plot is usually used to represent differences in the distributions of different categories of data for the same factor. In Matplotlib, we can use Matplotlib’s “native” method to draw a “ridgeline” plot, or we can use the JoyPy library to draw it.

sord_index = [i for i in group_data.color.unique()]
sord_index = sorted(sord_index, key=str.lower)
fig,ax = plt.subplots(figsize=(5.5,4.5), dpi=100)
for i,index in zip(range(len(sord_index)), sord_index):
	data = group_data.loc[group_data["color"]==index, "depth"].values
	x,y = NaiveKDE(kernel="Gaussian", bw=.8).fit(data).evaluate()
	ax.plot(x, 6*y+i, lw=.6, color="k", zorder=100-i)
	ax.fill(x, 6*y+i, lw=1, color="gray", alpha=.6, zorder=100-i)
	ax.grid(which="major", axis="y", ls="--", lw=.7, color="gray", zorder=-1)
	ax.yaxis.set_tick_params(labelleft=True)
	ax.set_yticks(np.arange(len(sord_index)))
	ax.set_yticklabels(sord_index)

We can use the JoyPy library to draw a histogram “ridgeline” plot for each group of data by setting the hist parameter in the joyplot() function to True. We can also apply color mapping to the “ridgeline” plot by setting the colormap parameter.

# Draw the histogram "ridgeline" plot
fig, axes = joypy.joyplot(group_data, by="color",
	column="depth", labels=sord_index, grid="y",
	linewidth=1, figsize=(7,6), color="gray",
	hist=True, xlabelsize=15, ylabelsize=15)
# Draw the gradient color-filled "ridgeline" plot
from colormaps import parula
fig, axes = joypy.joyplot(group_data, by="color",
	column="depth", labels=sord_index, grid="y",
	linewidth=1, figsize=(7,6), hist=False,
	colormap=parula, xlabelsize=15, ylabelsize=15)

Because the functionality of the JoyPy library is not yet sufficiently complete, readers are advised to use Matplotlib’s native method to draw “ridgeline” plots.

If you want to use continuous gradient colors to fill each group of data in a “ridgeline” plot and use continuous gradient color values to represent data magnitude, you can refer to the method for drawing a gradient color-filled density plot.

It should be noted that because the plotting script involves loop plotting statements, a clipping failure problem will occur when saving it as a vector file (such as a PDF file). To solve this problem, we only need to add the following code before writing the script.

    for i,index in zip(range(len(sord_index)),sord_index):
        data = group_data.loc[group_data["color"]==index,"depth"].values
        x,y = NaiveKDE(kernel="Gaussian",bw=.8).fit(data).evaluate()
        img_data = x.reshape(1,-1)
        ax.plot(x,6*y+i, lw=1,color="k",zorder=100 - i)
        fill_line, = ax.fill(x,6*y+i,facecolor="none")
        #ax.axhline(i,ls="--",lw=.7,color="gray",zorder=100 - i)
        ax.grid(which="major",axis="y",ls="--",lw=.7,color="gray",zorder=-1)
        #ax.set_xlim(50,72)
        ax.yaxis.set_tick_params(labelleft=True)
        ax.set_yticks(np.arange(len(sord_index)))
        ax.set_yticklabels(sord_index)
        ax.set_xlabel("Depth")
        ax.set_ylabel("Color")
        ax.tick_params(which ="both",top=False,right=False)
        ax.tick_params(which = "minor",axis="both",left=False,bottom=False)
        for spin in ["top","right","bottom","left"]:
            ax.spines[spin].set_visible(False)
        extent=[*ax.get_xlim(), *ax.get_ylim()]
        im = Axes.imshow(ax, img_data, aspect='auto',cmap="plasma",extent=extent)
        im.set_clip_path(fill_line)
    colorbar = fig.colorbar(im,aspect=10,shrink=0.5)
    colorbar.ax.set_title("Values",fontsize=10)
plt.show()

Drawing Multiple Density Plots in the Same Coordinate System #

When drawing multiple density plots in the same coordinate system, in addition to using the Matplotlib library for loop plotting, the Seaborn library can also be used for rapid plotting.

The figure below shows “multiple density plots in the same coordinate system” drawn using Matplotlib and Seaborn, respectively.

# Draw using Matplotlib
from scipy import stats
palette = ["#352A87", "#108ED2", "#65BE86", "#FFC337"]
fig,ax = plt.subplots(figsize=(4, 3.5), dpi=100)
for i, index, color in
	zip(range(len(palette)), data_df.columns, palette):
		data = data_df[index].values
		density = stats.kde.gaussian_kde(data)
		x = np.linspace(-2, 25, 500)
		y = density(x)
		ax.plot(x, y, lw=.5, color="k", zorder=5-i)
		ax.fill(x, y, color=color, label=index, alpha=.7)
ax.set_xlabel("Values")
ax.set_ylabel("Density")
ax.legend()

# Draw using Seaborn
fig,ax = plt.subplots(figsize=(4, 3.5), dpi=100)
sns.kdeplot(data=data_df, shade=True, palette= palette, alpha=.6, ax=ax)
ax.set_xlabel("Values")

Note that the default order of multiple density plots in the same coordinate system drawn using Seaborn differs from the Matplotlib plotting result.

When drawing Seaborn plotting objects in the editing environment of the ProPlot library, although both are advanced wrapper libraries developed based on Matplotlib, considerable differences still exist between them, making it impossible to form a unified syntax standard well in specific graph plotting. This results in weaker plotting customization operations when the ProPlot library draws Seaborn graph objects.
