human-writing：让中文写作有点“活人感”

September 14, 2026 · 8 min read

让 AI 写中文，有时候会得到一篇很工整的文章。句子通顺，段落也齐全，就是读着有点累，像在看一份说明书。最近看到一个专门处理这类问题的 Skill，叫 human-writing[1]，中文名是“活人感写作”。里面主要是 Markdown 写作规则，还有一个 Python 检查脚本。

调整方式 #

看它的规则，会发现它很在意动笔前的材料准备。比如写一篇评测，手里得有测试条件和结果；写个人经历，就得有具体发生过的事。材料不够时，可以再问几句、查查资料，实在没有多少可写的，篇幅短一点也没关系。

小说和故事有另一套要求，可以编人物和情节，也要交代清楚人物想做什么、实际做了什么，以及事情为什么会这样发展。

到了具体写作时，它会提醒模型看看一段话有没有新内容。一个结论换几种说法，很容易就凑出一整段，读者却没多知道什么。句子也尽量先把事情说清楚，再补时间、原因和条件，少绕几个弯。

还有一些我们读 AI 文章时经常碰到的写法，比如每段都用短句总结，或者连续几句排得整整齐齐。偶尔用一次没什么，整篇都这样，读起来就容易有模板感。

主要流程 #

先说明材料怎么准备、不同题材怎么处理，再给出写作和修改的流程。具体场景拆在几个文件里，想了解规则的话，可以按自己常写的类型看：

文件用途
forum-prose.md知乎、公众号、论坛长文、博客和行业解读
reality.md真人、历史、新闻、数据和个人经历
fiction.md小说、故事、虚构散文和对白
formats.md短内容、口播、演讲、教程和评测
revision.md初稿完成后的逐遍修改清单
check_prose.py检查成稿是否触及已经写明的硬规则
human-writing-lite.md适合直接粘贴到聊天窗口的精简版本

早期版本列了不少禁词和句式。用这种方式检查比较直接，不过模型有时换几个词，还是会写出差不多的句子。所以到了 v1.1.0，检查也开始关注整句话在表达什么。

比如“你以为……其实……”，有些地方确实需要解释误解，有些地方只是为了让后半句显得更有分量。这个版本主要想减少后面这种写法，也补了对整齐排比、过度抒情、句长和连词密度的检查。

作者也调整了一些容易误伤正常中文的规则。平时只用 ChatGPT、千问这类聊天产品的话，仓库里还有一个可以直接粘贴的精简版。

写评测时怎么用 #

拿 GPU 推理评测举个例子。把测试条件和结果一起给它，再说明哪些内容没测过，不要补写。下面只是一个提示词示例，实际用的时候，还需要填上吞吐和延迟的具体数值：

使用 $human-writing。

任务：把下面的 GPU 推理测试素材改写成公众号文章。

要求：保留测试条件、吞吐和延迟数据；不要补写没有测过的体验；读者是有部署经验的 AI 工程师；少用宣传口吻。

材料：
- GPU：RTX 4090
- 模型：某 7B 指令模型，4-bit 量化
- 并发：1、8、32
- 已知结果：并发提高后吞吐增加，但首 token 延迟也会上升

这份示例里的材料还比较少，只能交代测试设置和一个大致趋势。要写成完整评测，还得补上各档并发的实测数据。这样也方便回头检查，看看文章里哪些话有数据支持，哪些只是模型顺手加上的。

只用聊天窗口也可以 #

不支持 Skill 的聊天产品，也可以用类似的方法。先发写作需求和材料，再附上写作规则。下面这段是按项目思路改写的提示词，措辞放松了一些，方便直接使用；仓库里的 human-writing-lite.md 则是作者提供的版本。

请根据我提供的材料写稿，语气像平时给人讲事情，不用刻意写得很正式。写的时候留意下面几点。

先看看材料够不够。经历、数字和原话都可以用，缺少的信息先问我，或者在能查证的情况下补充公开资料。材料少就写短一点，不要编经历，也不要靠重复同一个道理凑篇幅。

有判断就直接说，再交代依据。不用为了引出观点，先替读者安排一个“你以为”的误解。禁止翻案腔，包括「不是A，而是B」「不在于A，而在于B」「你以为A，其实B」「表面上A，实际上B」「与其说A，不如说B」「A不重要，重要的是B」以及一切同类变形。

句子尽量先说清楚谁做了什么，再补充背景。少用“进行了优化”这类笼统的说法，能说具体改了哪里，就说具体。连词够用就行，不必每句话都加“然而”“因此”。

长短句自然穿插，不必每段都用一句短判断收尾。动作和原话已经能让人读出情绪，就不用再解释一遍。同一个词需要重复时可以重复，不用一直换同义词。

五、成稿不用破折号，冒号只用来引出人物原话，不用「说白了」「值得注意的是」「先说结论」，不用赋能、抓手、闭环、底层逻辑这类黑话。

写完再读一遍，删掉重复的话，检查有没有超出材料的判断。读着拗口或太像报告的地方，换成平时说话会用的表达。
